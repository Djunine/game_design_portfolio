# 游戏策划作品集

围绕《失落星船：马拉松》的系统研究，开展构筑挑战合约设计，并制作局部可玩原型。当前重点是展示系统分析、规则表达、设计取舍及规则与实现的对应。

**建议顺序：系统拆解 → 合约设计 → 执行样例 → 可玩 Demo。**

[一页阅读导引](docs/阅读导引.pdf) · [网页版阅读入口](index.html) · [试玩与源项目下载页](https://github.com/Djunine/game_design_portfolio/releases)

## 两个项目，一条主线

| 项目 | 阅读重点 | 入口 |
|---|---|---|
| 系统拆解 | 核心循环、系统关系、参与负担分析与当前合约提案 | [项目说明](projects/marathon_analysis/README.md) |
| 构筑挑战合约 | 条件不同的合约、成长与奖励边界、执行样例和 Godot 原型 | [项目说明](projects/contract_system/README.md) |

## 当前版本

- 文档统一包1.1；拆解案为23页中文修订版，机制研究基准仍为2026-10-18。

- Windows运行包由Releases提供；请以下载页实际发布的附件为准。仓库中保留展开的源项目，便于阅读与复测。

## 贡献与验证边界

个人练习，非官方功能或商业上线项目。本人参与目标与范围讨论、合约规则取舍、反馈要求和早期原型试玩；资料整理、文稿草拟、程序及自动检查有AI辅助。新版人工验收与独立讲解仍需继续补充。

功能检查不能替代真实玩家测试，不宣称已经证明降低压力、提高留存或完成正式程序/美术联调。各项已实现、暂未实现及验证范围见项目说明。
