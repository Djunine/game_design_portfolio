## 研究范围

机制研究保留2026-10-18基准；2026-10-27的修订只处理语言和提案范围，不把旧研究写成当前实装状态。正文使用中文功能称呼，原文检索词集中在末页；部分功能称呼不代表官方统一译名。

本版保留机制分析，仅在提案部分讨论当前合约方案；摘要、诊断、图表、目录和验证章节已经同步。机制事实、策划分析与个人提案分别标注。

## 与后续作品的关系

拆解案提供研究依据；合约设计案给出针对选定玩家的规则与取舍；可玩原型验证其中一份合约的局部行为。不以原型运行结果反推原游戏机制，也不宣称已经验证真实玩家效果。
