# 《失落星船：马拉松》系统拆解

**类型：**个人游戏系统研究与改进提案  
**研究日期：**2026 年 10 月 18 日

## 30 秒概览

本案从玩家每局的目标、能力、信息和资产出发，分析探索、交战、撤离如何影响下一局的选择。

**核心判断：**装备损失让决策有后果；改进重点在于帮助玩家理解风险、承担失败成本，并在失败后保留重新选择的空间。
