# 构筑挑战合约系统设计

**类型：**个人系统策划练习  
**时间：**2026 年 10 月

基于《失落星船：马拉松》的玩法研究，尝试设计一条以 PvE 合约为目标、可独立推进的成长路径。

## 核心流程

接取合约 → 局内完成目标 → 成功撤离 → 结算经验与解锁内容。

## 本项目展示什么

- **系统设计：**合约目标、奖励规则、失败边界及成长解锁。
- **设计取舍：**单人成长、撤离决策，以及与正式游戏经济的隔离。
- **执行样例：**配置字段、界面需求和验收用例。

本项目是个人设计练习，并非游戏官方或已上线功能。网页按钮演示的是规则流程，不包含实际战斗；示例数值未经真实玩家测试。
