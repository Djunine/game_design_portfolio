# 构筑挑战合约系统设计

**类型：**个人系统策划练习  
**时间：**2026 年 10 月

基于《失落星船：马拉松》的玩法研究，尝试设计一条以 PvE 合约为目标、可独立推进的成长路径。

## 核心流程

接取合约 → 局内完成目标 → 成功撤离 → 结算经验与解锁内容。

## 本项目展示什么
  projects/contract_system/构筑挑战合约_主方案.pdf
  projects/contract_system/构筑挑战合约_执行样例.pdf
- 合约规则、奖励及失败边界
- 主流程的交互演示
- 配置字段、界面需求和验收用例样例

本项目不是游戏官方或已上线功能。交互演示用于说明规则，尚未接入游戏；示例数值未经真实玩家测试。
